# 결과 (중간 결과, 논문 투고 전)

모든 수치는 공식 test 세트에서 한 번 측정한 값입니다. 확신도 종류 · 임계값 · 하이퍼파라미터는 tune 세트에서만 정했습니다.
**자동화율** = 정밀도 99%를 목표로 tune에서 정한 확신도 임계값을 test에 적용했을 때, 사람 확인 없이 처리되는 질의 비율.

## 1. 검색형 인식 (Search, Don't Spell)

비교군 = 같은 train으로 파인튜닝한 생성형 OCR 3종(PP-OCRv5, PaddleOCR-VL-1.6, OvisOCR2), 생성 문자열을 그대로 레코드로 사용.
"비교군 최고" = 같은 지표에서 3종 중 가장 좋은 값.

| 데이터셋 | test | 레코드 정확도 (제안 / 비교군 최고) | 자동화율 @ 정밀도 99% (제안 / 비교군 최고) | McNemar |
|---|---:|---:|---:|---|
| AI Hub 053 한국어 서식 (칼럼 = 이미지 여러 장) | 1,751명 | **99.25** / 96.75 (+2.50) | **99.97** / 87.99 | p < 1e-60 |
| HANA 덴마크어 이름 (한 이미지 안 여러 칼럼) | 55,822 | **96.88** / 85.52 (+11.36) | **86.51** / 32.57 | p < 1e-300 |
| IAM 영어 문장 줄 (칼럼 없음) | 2,915 | **98.66** / 58.83 (+39.83) | **99.59** / 9.19 | p < 1e-300 |

### 길이 · 칼럼 수 사다리 (AI Hub, 레코드 정확도 %)

| 단계 | 평균 글자 수 | 제안 | 생성형 최고 | 격차 (%p) |
|---|---:|---:|---:|---:|
| L1 이름 | 3.0 | 98.06 | 98.63 | −0.57 |
| L3 주소 3토큰 | 12.3 | 99.37 | 96.92 | +2.45 |
| L6 주소 6토큰 | 22.5 | 98.94 | 93.01 | +5.93 |
| F2 이름+생년월일 | 9.0 | 99.77 | 97.72 | +2.05 |
| F3 이름+생년월일+주소 | 23.5 | 99.43 | 94.40 | +5.03 |

### 멀티 칼럼

- 칼럼 하나를 비워도(이미지 · DB 양쪽) 제안 모델은 99.37–99.89%.
- 같은 칼럼을 한 줄 이미지로 이어 붙이면(F3 → C3) 생성형은 1.26–6.28%p 떨어지고 제안 모델은 +0.11%p.
- 생성형의 F3 오답 중 88.8–97.3%는 **한 칼럼만** 틀린 레코드 — 검색은 나머지 칼럼이 정답 레코드로 끌어온다.
- HANA 단어 수 사다리: 격차 H2 +7.5 → H5+ +34.0%p.

### 한계 (전체 지표는 논문 부록에 공개 예정)

- DB 후보를 다시 채점하는 강한 비교군(생성 + DB 후보 재채점) 대비로는 유의한 우위가 확인되지 않았다(이전 프로토콜 분석).
- 처리 시간은 데이터셋에 따라 비교군보다 빠르거나 비슷하거나 느리다.
- DB에 없는 레코드의 오수락에서 불리하다.

## 2. 손글씨 KIE (Ask, Read, Verify)

입력 = 서식 페이지 전체(검출 · crop 없음) + 키 목록(조합 · 순서 무작위), 출력 = 키 순서대로 값. test 195장 · 585 질의, 질의 완전 일치(요청 키 값이 모두 정답).
대조군 = 정답 위치로 잘라 준 칼럼 crop(검출이 완벽하다고 가정)을 파인튜닝 OCR로 읽음 — 대조군에 유리한 설정.

| 방법 | 검출 · crop | 그대로 | + 레코드 DB 검증 |
|---|---|---:|---:|
| KIE · OvisOCR2 | 없음 | 84.8 | **98.1** |
| KIE · PaddleOCR-VL-1.6 | 없음 | 78.6 | 96.8 |
| crop + OCR 3종 (대조군) | 완벽 가정 | 93.5–94.5 | 98.3–98.6 |

- 키 순서를 바꿔도 같은 답 94.6%, 값이 다른 키에 붙는 결합 오류 0%.
- 학습 데이터 10% / 30% / 100%: 레코드 DB 검증 뒤 90.9 / 95.6 / 96.8% (PaddleOCR-VL-1.6).
- DB에 없는 사람 비율 0 / 5 / 20%: KIE + 되돌림 96.8 / 94.7 / 90.1%, DB 밖 질의만 보면 VLM 자체 정확도(약 67–70%)로 떨어진다.
- 파인튜닝 없는 범용 VLM은 30%(20건 표본): 손글씨 오독과, 합성 주소를 실제 지명으로 "교정"하는 오류.

진행 중: 인쇄 항목명을 키로 쓰는 일반형 데이터(서식 약 5.6만 장, 키 수백 종, '[없음]' 네거티브, 처음 보는 서식 분할), 우도 기반 레코드 검증.
