○ VLM · OCR 출력 그대로 → ● 요청 키를 한 레코드로 묶어 DB와 대조한 뒤.

검출 없이 페이지 전체를 읽는 KIE는 그대로는 대조군보다 낮지만, 레코드 DB 검증 뒤에는 검출이 완벽하다고 가정한 OCR 파이프라인과 거의 같다.

키 순서를 바꿔도 같은 답 94.6% · 값이 다른 키에 붙는 결합 오류 0% · 학습 데이터 10%로도 90.9%.
